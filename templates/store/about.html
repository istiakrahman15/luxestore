About

A storefront built to be read

LuxeStore isn't a real business — it's a portfolio piece. The goal was to build a storefront that looks like it belongs to a small, considered brand, while keeping the Django code underneath clean enough for another developer to open and understand in five minutes.

Deliberately missing: accounts, a cart, checkout, and payments. Adding those would shift the focus from "can this person structure a Django app well" to "can this person wire up a payment provider," which is a different (and much longer) project.

Two models

Category and Product, related with a simple foreign key.

Branded admin

Image previews, search, filters, and ordering — no third-party admin theme.

Hand-built theme

CSS variables drive dark/light mode — no theming library.

Built by

Istiak

Creative developer working across React, Laravel, WordPress, and Django. This project is part of an ongoing portfolio of self-contained builds.
