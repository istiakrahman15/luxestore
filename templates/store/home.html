Why LuxeStore

Built the way real catalogs are built

This project exists to show working Django patterns — not to sell anything. Every section below maps to something in the codebase: a model, a query, or an admin tweak.

Real search & filtering

Query-string driven search and category filters, powered by Django ORM lookups.

Dark & light mode

A CSS-variable theme system toggled with vanilla JS and remembered per browser.

Clean admin experience

A branded Django admin with image previews, filters, search, and ordering.

Mobile-first & fast

Bootstrap 5 grid, no build step, no heavy JS — just HTML, CSS, and a light script.
